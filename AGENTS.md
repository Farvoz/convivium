# Convivium

Игра для мобильных устройств в вебе.

## Источники

- `Правила игры.md` - здесь содержатся изначальные правила игры;
- `Требования к UI.md` - описание желаемого визуала;
- `cards.js` - описание используемых карт (экспонирует globals `cards`);
- `engine.js` — игровой движок (экспонирует globals `Convivium`);
- `test.js` — тесты и прогон партий (`node --test`);
- `index.html` — точка входа, подключает `cards.js` → `engine.js` → `app.js`;
- `app.js` — браузерный UI-слой (IIFE, берёт globals из `cards.js`/`engine.js`);
- `style.css` — стили, мобильная вёрстка;
- `faces/` - картинки персонажей (`face_*.png`);
- `sw.js` — service worker (PWA, регистрируется только на `https`);
- `manifest.webmanifest` — PWA-манифест;
- `icon.svg` — иконка приложения / Apple touch icon;
- `package.json` — `npm test` запускает `node --test`.

## Режим игры

Соло: один игрок, цель — дожить до конца колоды и набрать как можно больше очков.

## Как запустить

- Тесты: `npm test` (или `node --test`).
- Игра:
  - Напрямую открыть `index.html` через `file://` — работает без PWA;
  - Либо поднять локальный сервер (`npx serve` / `python -m http.server`) — тогда доступна установка как PWA на iOS/Android.

## Технологии

HTML + CSS современных версий.
PWA опционален: service worker регистрируется только при `location.protocol === 'https:'`,
на `file://` игнорируется, поэтому игра работает обоими способами.
Подключение через относительные пути на файловой системе.
