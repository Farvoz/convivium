# Convivium

Игра для мобильных устройств в вебе.

## Источники

- `Правила игры.md` - здесь содержатся изначальные правила игры;
- `cards.js` - здесь описание используемых карт;
- `engine.js` — игровой движок;
- `test.js` — тесты и прогон партий;
- `Требования к UI.md` - описание желаемого визуала
- `faces` - тут лежат картинки нескольких персонажей

## Технологии

HTML + CSS современных версий.
PWA приложение для установки на iOS.
Будет просто index.html и подключаться через относительный пути на файловой системе.
