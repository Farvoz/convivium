# Требования к UI

## Палитра и стиль
- Светлый бежевый фон + тематика "вечеринки". Шрифт читаемый на мобайле, крупные размеры, достаточный контраст.

## Экраны и поток
1. **Start** 
2. **Prep (Особая подготовка)** показ 3 открытых карт, выбор 1 бесплатно в Дом; остальные — в сброс. Отдельный шаг.
3. **Game:** основной экран (см. ниже).
4. **End:** Победа/Поражение, итоговые очки, «Играть снова» (возврат на Start).

## Композиция игрового экрана (портрет, сверху→вниз)
- Тонкая **шапка**: показывается последнее событие. ПО тапу открывается сверху шторка с логом всех событий.
- Узкая лента **Угроза** (карты угроз; при 3+ — визуальное предупреждение).
- **Текущая карта** по центру (крупно).
- Узкая лента **Дом** (купленные).
- Нижня панель показывается количество оставшихся карт и кнопку "Сброс" (для просмотра сброшенных карт)

## Рендер карты
- Картинка — **только верхняя половина** [картинки будут потом]. Низ описания рендерит UI.
- Под картинкой — блок: **название** + **ПО звёздами** (число ★ = |vp|; ПО 0 не выводим; отрицательное — «−» + звёзды красным). Теги
- Ниже — **текст эффекта** из `cards.js` (`description`).

## Управление и выборы
- Можно смахнуть центральную открытую карту влево (сбросить) или вправо (купить)- аля Тиндер.
- Тап по карте в лентах Дом/Угроза открывает детальный layout (полная карта + вложения `attach`). Для активного выбора тап резолвит выбор, а не открывает деталку.

## Анимации
Игрок должен видеть, какие действия происходят. Даже если автоматически.

- открытие новой карты в центре;
- перемещение её в нужную зону (Угроза, Дом, Сброс);

## Нефункциональные
- Mobile-first (портрет, тач); офлайн (относительные пути); ленты Угроза/Дом — горизонтальный скролл при переполнении.
